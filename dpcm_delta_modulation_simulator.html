Assumptions & formulas used

Sampling

Internal sampling rate is fixed at fs = 8000 Hz. The "samples shown" control only changes how many samples are generated and plotted, not the underlying rate.

First-order DPCM predictor

x̂[n] = a · x_r[n−1]   e[n] = x[n] − x̂[n]   x_r[n] = x̂[n] + e_q[n]

Prediction always uses the reconstructed sample x_r[n−1], not the original x[n−1] — this is what makes it a closed-loop coder, so encoder and decoder stay in sync. The error quantizer's range is set automatically from the signal's own maximum sample-to-sample change, scaled up 20% as headroom, so the quantizer is neither wastefully wide nor clipping.

The very first sample x_r[0] is coded directly with a plain PCM quantizer at the same bit depth, since there is no previous sample to predict from yet.

Plain PCM comparison

Uses a uniform quantizer directly on x[n], at the same bit depth as the DPCM error quantizer, over the full amplitude range, for a fair bit-for-bit comparison.

Delta modulation

bit[n] = +1 if x[n] ≥ x_r[n−1], else −1   x_r[n] = x_r[n−1] + bit[n]·Δ

The reconstruction starts at x_r[0] = 0, the standard assumption for a 1-bit delta modulator with no separate start-up channel.

Adaptive delta modulation

A simplified doubling scheme: Δ resets to Δmin = Δ/4 whenever the bit direction changes, and doubles (capped at Δmax = 4·Δ) whenever two consecutive bits share the same direction. This is the same idea behind classic schemes like continuously variable slope delta modulation, simplified for teaching.

Mandatory validation

Every consecutive pair of reconstructed samples is checked: |x_r[n] − x_r[n−1]| must equal the Δ that was in force at step n, within floating-point tolerance. This is checked for both plain and adaptive delta modulation.

Theoretical slope-overload / granular-noise prediction

Computed directly from the signal, with no dependence on the bitstream: let Smax be the largest sample-to-sample change in x[n], and Srms its root-mean-square change.

  • Slope overload is predicted when Δ < Smax — the staircase physically cannot move fast enough for the steepest part of the signal.
  • Granular noise is predicted when Δ > 2.5 × Srms — the step is oversized relative to what the signal typically needs, so it overshoots on quiet stretches.

MSE vs. step size sweep

Δ is swept on a log scale between 0.002 and 2.5× the current amplitude, using plain (non-adaptive) delta modulation on the currently selected waveform and frequency.
